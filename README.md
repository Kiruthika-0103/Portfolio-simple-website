# Personal Portfolio Website

A simple and responsive personal portfolio website built using **HTML and basic CSS**. This project includes two pages: a home page to introduce myself and a contact page to provide contact information.

## 📄 Pages

- **index.html** – The main page of the portfolio.
- **contact.html** – The contact page with contact details.
- **style.css** – The stylesheet used to design and style both pages.

## 🛠️ Technologies Used

- HTML5
- CSS3

## 🚀 Features

- Simple and clean design
- Easy navigation between pages
- Basic CSS styling
- Beginner-friendly project structure

## 📂 Project Structure

```text
portfolio/
├── index.html
├── contact.html
└── style.css
```

## 🎯 Purpose

This project was created to practice basic HTML and CSS skills and build a simple personal portfolio website.
